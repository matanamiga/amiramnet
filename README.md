# Inside Job Flutter App

This repository contains a small Flutter prototype for **Inside Job**, a personal productivity and health tracker. It currently supports simple in-memory weight and task tracking using Riverpod.

## Building

Flutter and Dart must be installed. Then run:

```bash
flutter pub get
flutter run
```

This prototype is not yet connected to Firebase or persistent storage. See `docs/SRS.md` for the full requirements to be implemented.
